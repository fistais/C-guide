C++ с нуля до функций
0. Что вообще такое C++?
C++ — язык программирования.
Когда мы пишем программу, мы фактически говорим компьютеру:
«Сделай вот это, потом вот это, потом вот это».
Например:
#include <iostream>

int main()
{
std::cout << "Hello!";
}
Программа выводит:
Hello!
Пока тебе достаточно понимать структуру:
#include <iostream>
Подключает возможности для работы с вводом/выводом.
int main()
{

}
main — место, с которого начинается выполнение программы.
std::cout << "Hello!";
Выводит текст на экран.

1. Как выглядит программа C++
Минимальная программа:
#include <iostream>



int main()
{
std::cout << "Hello!";
return 0;
}
Разберём по частям.
#include <iostream>
Подключает библиотеку iostream.
Она нужна, например, для:
std::cout
и
std::cin
То есть для вывода и ввода.
int main()
Главная часть программы.
Компьютер начинает выполнение программы именно отсюда.
Пока просто запомни:
int main()
{
// здесь пишем программу
}
{ }
Фигурные скобки обозначают блок кода.
Всё между:
{

}
относится к этому блоку.
;
Точка с запятой обозначает конец инструкции.
Например:
int age = 18;
std::cout << age;
Каждая инструкция заканчивается ;.
2. Комментарии
Комментарии — это текст внутри программы, который компьютер не выполняет.
Однострочный комментарий:

Многострочный:

многострочный

Комментарии очень полезны для объяснения кода.

5. Переменные
Теперь самое важное.
Переменная — это место в памяти компьютера, где хранится какое-то значение.
Например, нам нужно сохранить возраст человека.
int age = 18;

int      age      =      18

Создай переменную age, которая хранит целое число, и положи туда 18.

{

Результат:

36. while
Смысл:
Пока условие истинно — повторяй.
Например:
int number = 1;

while (number <= 5)
{
std::cout << number << "\n";

number++;

}
Результат:
1
2
3
4
5
37. Как работает while
Начинаем:
number = 1;
Проверяем:
1 <= 5 → true
Выводим:
1
Увеличиваем:
number++;
Теперь:
number = 2
Снова проверяем:
2 <= 5 → true
И так далее.
Когда:
number = 6
проверка:
6 <= 5
даёт:
false
Цикл заканчивается.
38. Опасность бесконечного цикла
Например:
int number = 1;

while (number <= 5)
{
std::cout << number;
}
Здесь number никогда не увеличивается.
Поэтому условие всегда:
1 <= 5
и цикл бесконечный.
Поэтому нужно внимательно следить за изменением переменной.
39. do while
Похож на while, но есть важная разница.
do
{
// код
}
while (условие);
Код выполняется минимум один раз.
Например:
int number = 10;

do
{
std::cout << number;
number++;
}
while (number < 5);
Хотя:
10 < 5
неверно, число 10 всё равно будет выведено один раз.
Потому что сначала выполняется код, а потом проверяется условие.
40. while vs do while
while
Сначала проверка:
проверить → выполнить → проверить → выполнить
do while
Сначала выполнение:
выполнить → проверить → выполнить → проверить
Поэтому do while гарантированно выполняется хотя бы один раз.

61. Приведение типов
Иногда нужно превратить один тип в другой.
Например:

Это можно сделать автоматически.
Но есть и явное преобразование:

Например, это полезно для деления:
int a = 10;
int b = 3;

double result = static_cast<double>(a) / b;
Теперь получится:

62. Область видимости переменной
Это тоже важно понимать до функций.
Например:

{

Переменная number существует только внутри этих {}.

Потому что number была создана снаружи блока.
63. Что такое память
Вот здесь начинается важная часть для твоей темы по архитектуре ЭВМ.
Когда мы пишем:
int number = 10;
компьютер должен где-то хранить 10.
Он выделяет участок памяти.
Условно:
Память
┌─────────────┐
│     10      │ ← number
└─────────────┘
У каждого участка памяти есть адрес.
Например, условно:
0x0012FF40
В реальности адрес будет другим.
64. Адрес переменной
У переменной есть адрес в памяти.
Получить адрес можно через:
&
Например:
int number = 10;

std::cout << &number;
Компьютер выведет что-то вроде:
0x7ff...
Это адрес переменной number в памяти.
65. Указатели — самое первое знакомство
До функций тебе достаточно понять базовую идею.
Указатель — переменная, которая хранит адрес другой переменной.
Например:
int number = 10;

int* pointer = &number;
Здесь:
&number
означает:
адрес number
А:
int* pointer
означает:
pointer может хранить адрес переменной типа int.
66. Получение значения через указатель
Если:
int number = 10;
int* pointer = &number;
то:
*pointer
означает:
значение, которое находится по адресу, хранящемуся в pointer.
Поэтому:
std::cout << *pointer;
выведет:
10
67. Главное различие & и *
Это часто вызывает путаницу.
&number
→ адрес number.
А:
*pointer
→ значение по адресу, который хранится в pointer.
Можно представить:
number
┌──────┐
│  10  │
└──────┘
↑
│ адрес
│
pointer
┌──────────────┐
│ адрес number │
└──────────────┘
68. Ссылки
В C++ есть ещё ссылка.
Например:
int number = 10;

int& reference = number;
reference становится другим именем для number.
То есть:
reference = 20;
изменит и:
number
Теперь:

74. Ещё один важный пример — поиск максимума
Допустим, пользователь вводит 3 числа.
#include <iostream>

{

{  
    max = b;

потом проверяем c

75. Что такое алгоритм
Алгоритм — последовательность действий для решения задачи.
Например, задача:
Найти сумму чисел от 1 до 5.
Алгоритм:

1. Создать переменную sum = 0


2. Взять число 1


3. Добавить его к sum


4. Взять число 2


5. Добавить его к sum


6. ...


7. Получить результат
В C++:
int sum = 0;



for (int i = 1; i <= 5; i++)
{
sum += i;
}

std::cout << sum;
Результат:
15

80. Самая важная схема C++ до функций
Если очень сильно упростить весь этот материал, у тебя должна сложиться вот такая картина:
ПРОГРАММА
│
├── переменные
│      └── хранят данные
│
├── ввод
│      └── cin
│
├── обработка
│      ├── математика
│      ├── сравнения
│      └── логика
│
├── условия
│      ├── if
│      └── switch
│
├── повторение
│      ├── for
│      ├── while
│      └── do while
│
├── массивы
│      └── несколько значений
│
├── строки
│      └── текст
│
└── память
├── адрес
├── указатель
└── ссылка
А следующий большой шаг после этого — функции.
И вот там уже появится очень важная идея:
main()
{
...
}
мы сможем разделять на отдельные части:
main()
{
...
calculate();
...
}
То есть функция позволяет вынести отдельную часть программы в отдельный блок и потом вызывать её, когда нужно.
Минимальная проверка перед функциями
Если ты можешь самостоятельно понять, что делает этот код:
#include <iostream>



int main()
{
int numbers[5];

for (int i = 0; i < 5; i++)  
{  
    std::cin >> numbers[i];  
}  

int max = numbers[0];  

for (int i = 1; i < 5; i++)  
{  
    if (numbers[i] > max)  
    {  
        max = numbers[i];  
    }  
}  

std::cout << "Max: " << max;  

return 0;

}
и можешь объяснить:
что такое int, зачем numbers[5], почему индексы начинаются с 0, что делает for, зачем i++, что проверяет if, зачем max = numbers[0] и почему второй цикл начинается с i = 1
— значит, ты уже практически готов переходить к функциям.
А если какие-то из этих вещей пока выглядят как магия — это абсолютно нормально: лучше сначала закрепить переменные → условия → циклы → массивы на простых задачах, и только потом идти в функции.
