1. Что такое C++

C++ — это язык программирования.

На C++ можно создавать:

- программы для компьютера;
- игры;
- приложения;
- операционные системы;
- программы для работы с устройствами.

Пример самой простой программы:

#include <iostream>

using namespace std;

int main()
{
    cout << "Hello!";
    return 0;
}

Результат:

Hello!

💡 Запомни

Почти любая простая программа на C++ начинается с функции:

int main()

Именно с неё начинается выполнение программы.

2. Структура программы

Разберём программу по частям:

#include <iostream>

using namespace std;

int main()
{
    cout << "Hello!";
    return 0;
}

"#include <iostream>"

Подключает библиотеку, которая нужна, например, для:

- "cout" — вывод текста;
- "cin" — ввод данных.

"using namespace std;"

Позволяет писать:

cout

вместо:

std::cout

"int main()"

Главная функция программы.

Именно отсюда начинается выполнение программы.

"{ }"

Фигурные скобки обозначают тело функции.

То есть всё между:

{
    ...
}

относится к функции "main".

"return 0;"

Сообщает, что программа завершилась нормально.

💡 Запомни

Минимальная схема:

подключили библиотеки
        ↓
      main()
        ↓
   команды программы

3. Комментарии

Комментарий — это текст для программиста.

Компьютер его не выполняет.

Однострочный комментарий

Используется "//":

// Это комментарий

cout << "Hello";

Всё после "//" до конца строки игнорируется.

Многострочный комментарий

Используются:

/*
   Это многострочный
   комментарий
*/

Например:

/*
   Программа выводит
   приветствие
*/

cout << "Hello";

💡 Зачем нужны комментарии?

Чтобы объяснить, что делает код.

Например:

// Выводим имя пользователя
cout << name;

Комментарии особенно полезны в учебных работах.

4. "cout" — вывод на экран

"cout" используется для вывода информации на экран.

Например:

cout << "Hello!";

На экране появится:

Hello!

Можно выводить числа:

cout << 25;

Результат:

25

Можно выводить несколько значений:

cout << "Возраст: " << 18;

Результат:

Возраст: 18

Почему используются "<<"?

Оператор:

<<

передаёт данные в "cout".

Можно представить это так:

"Возраст: "  →  cout
18           →  cout

Поэтому:

cout << "Возраст: " << 18;

"std::cout"

На самом деле "cout" находится внутри пространства имён "std".

Поэтому полный вариант:

std::cout << "Hello!";

Если написать:

using namespace std;

можно сокращённо:

cout << "Hello!";

💡 Запомни

cout << "текст";

означает:

«вывести текст на экран.»

5. Перенос строки: "\n" и "endl"

Если написать:

cout << "Hello";
cout << "World";

получится:

HelloWorld

Потому что после "Hello" курсор не переходит на новую строку.

"\n"

Чтобы перейти на новую строку, можно использовать:

cout << "Hello\n";
cout << "World";

Результат:

Hello
World

Можно использовать несколько переносов:

cout << "Hello\nWorld\nC++";

Результат:

Hello
World
C++

"endl"

Есть ещё один способ:

cout << "Hello" << endl;
cout << "World";

Результат такой же:

Hello
World

Что лучше использовать?

Для начала проще запомнить:

\n

Это обычный перенос строки.

"endl" тоже работает, но технически делает немного больше, чем просто переносит строку.

💡 Запомни

cout << "Hello\n";

означает:

«вывести "Hello" и перейти на новую строку.»
