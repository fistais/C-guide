1. Что такое C++

C++ — это язык программирования.

Когда мы пишем программу, мы фактически говорим компьютеру:

««Сделай вот это, потом вот это, потом вот это».»

Например:

#include <iostream>

int main()
{
    std::cout << "Hello!";
}

Программа выведет:

Hello!

Пока достаточно понимать общую структуру:

#include <iostream>

Подключает возможности для работы с вводом и выводом.

int main()
{
    
}

"main" — место, с которого начинается выполнение программы.

std::cout << "Hello!";

Выводит текст на экран.

---

2. Как выглядит программа C++

Минимальная программа:

#include <iostream>

int main()
{
    std::cout << "Hello!";
    return 0;
}

"#include <iostream>"

Подключает библиотеку "iostream".

Она нужна, например, для:

std::cout
std::cin

То есть для вывода и ввода.

"int main()"

Главная часть программы.

Компьютер начинает выполнение программы именно отсюда.

Пока просто запомни:

int main()
{
    // здесь пишем программу
}

"{ }"

Фигурные скобки обозначают блок кода.

Всё между ними относится к этому блоку.

";"

Точка с запятой обозначает конец инструкции.

Например:

int age = 18;
std::cout << age;

3. Комментарии

Комментарии — это текст внутри программы, который компьютер не выполняет.

Однострочный комментарий:

// Это комментарий

Например:

int age = 18; // возраст

Многострочный комментарий:

/*
    Это
    многострочный
    комментарий
*/

Комментарии полезны для объяснения кода.

4. Вывод информации — cout

Для вывода используется:

std::cout

Например:

#include <iostream>

int main()
{
    std::cout << "Hello!";
}

На экране:

Hello!

Можно вывести несколько вещей:

std::cout << "Hello!" << " How are you?";

Получим:

Hello! How are you?

5. Перенос строки

Для переноса строки можно использовать:

\n

Например:

std::cout << "Hello\n";
std::cout << "World";

Результат:

Hello
World

Также существует:

std::endl

Например:

std::cout << "Hello" << std::endl;
std::cout << "World";

Получится то же самое.

«Для начала можешь использовать "\n".»

6. Переменные

Это одна из самых важных тем.

Переменная — это место в памяти компьютера, где хранится какое-то значение.

Например, нам нужно сохранить возраст человека:

int age = 18;

Здесь:

Часть| Значение
"int"| тип
"age"| имя
"="| присваивание
"18"| значение

То есть:

«Создай переменную "age", которая хранит целое число, и положи туда "18".»

Потом мы можем её вывести:

#include <iostream>

int main()
{
    int age = 18;

    std::cout << age;
}

Результат:

18

int age = 18;

Получим:

19

Или можем изменить переменную:

int age = 18;

age = 19;

std::cout << age;

Получим:

19

int age = 18;

Здесь:

«В этой переменной будет целое число.»

"age"

Название переменной.

"="

Присваивание.

9. Основные типы данных

До функций обязательно нужно знать несколько основных типов.

"int"

Целые числа:

int age = 18;
int number = -25;
int money = 1000;

Например:

-100
0
15
1000

---

"double"

Числа с дробной частью:

double price = 15.5;
double height = 182.7;
double result = 10.5;

---

"float"

Тоже дробные числа:

float temperature = 25.5;

На начальном этапе чаще используй "double", если нет специальной причины использовать "float".

---

"char"

Один символ:

char letter = 'A';

Обрати внимание:

'A'

используются одинарные кавычки.

Например:

char symbol = '7';

Это именно символ "'7'", а не число "7".

---

"bool"

Логическое значение.

Может быть только:

true
false

Например:

bool isStudent = true;
bool isAdult = false;

---

"string"

Для текста.

Нужно подключить:

#include <string>

Пример:

std::string name = "Alex";

Текст записывается в двойных кавычках:

"Alex"

18

19. Целочисленное деление

Если:

int a = 10;
int b = 3;

std::cout << a / b;

Результат:

3

А не:

3.333333

Почему?

Потому что оба числа имеют тип "int".

При делении "int" на "int" результат получается целым.

Если нужны дроби:

double a = 10;
double b = 3;

std::cout << a / b;

Получим примерно:

3.33333

20. Остаток от деления "%"

Оператор:

%

даёт остаток от деления.

Например:

10 % 3

Результат:

1

Потому что:

10 / 3 = 3
остаток = 1

Ещё пример:

8 % 2

Результат:

0

Оператор "%" очень полезен.

Например, чтобы определить, чётное число или нет:

if (number % 2 == 0)
{
    std::cout << "Четное";
}

Почему это работает, разберём дальше.

21. Приоритет операций

int result = 2 + 3 * 4;

3 * 4 = 12

Потом:

Получаем:

14

Если нужны скобки:

int result = (2 + 3) * 4;

Получим:

20

25. Очень важная разница: "=" и "=="

Новички постоянно путают эти операторы.

"="

Присваивание:

age = 20;

То есть:

«Положить "20" в "age".»

26. "if" — условие

Теперь программа может принимать решения.

Например:

«Если возраст 18 или больше — вывести «Совершеннолетний».»

int age = 20;

if (age >= 18)
{
    std::cout << "Совершеннолетний";
}

"if" означает:

«если»

Условие:

age >= 18

Если оно истинное, выполняется код внутри "{}".

---

27. Как программа думает в "if"

Допустим:

int age = 16;

if (age >= 18)
{
    std::cout << "Можно";
}

Программа проверяет:

16 >= 18 ?

Ответ:

false

Поэтому код внутри "if" не выполняется.

Если:

int age = 20;

Проверка:

20 >= 18 ?

Ответ:

true

Поэтому выводится:

Можно

28. "else"

Что делать, если условие не выполнилось?

Используем:

else

Пример:

int age = 16;

if (age >= 18)
{
    std::cout << "Совершеннолетний";
}
else
{
    std::cout << "Несовершеннолетний";
}

Получим:

Несовершеннолетний

То есть:

if    → если условие верно
else  → иначе

29. "else if"

Можно проверять несколько вариантов.

int number;

if (number > 0)

}
else if (number < 0)
{
    std::cout << "Отрицательное";
}
else
{
    std::cout << "Ноль";
}

Если пользователь вводит:

10

получаем:

Положительное

Если:

-5

получаем:

Отрицательное

Если:

0

получаем:

Ноль

30. Логические операторы

Иногда нужно проверить несколько условий одновременно.

Основные:

&&
||
!

"&&" — И

Оба условия должны быть верными.

Например:

age >= 18 && age <= 60

То есть:

«возраст от 18 до 60 включительно.»

---

"||" — ИЛИ

Достаточно, чтобы хотя бы одно условие было истинным.

number == 1 || number == 2

То есть:

«число равно 1 или равно 2.»

---

"!" — НЕ

Меняет "true" на "false" и наоборот.

bool isStudent = true;

if (!isStudent)
{
    // ...
}

"!isStudent" означает:

«НЕ студент.»

---

int age;

std::cin >> age;

if (age >= 18 && age <= 60)
{
    std::cout << "Подходит";
}
else
{
    std::cout << "Не подходит";
}

32. Вложенный "if"

"if" можно помещать внутрь другого "if".

Например:

int age = 20;
bool hasTicket = true;

if (age >= 18)
{
    if (hasTicket)
    {
        std::cout << "Можно войти";
    }
}

Сначала проверяется возраст.

Если возраст подходит, проверяется наличие билета.

33. "switch"

Если нужно сравнить одну переменную с конкретными значениями, удобно использовать "switch".

Например:

int number;

std::cin >> number;

switch (number)
{
case 1:
    std::cout << "Понедельник";
    break;

case 2:
    std::cout << "Вторник";
    break;

case 3:
    std::cout << "Среда";
    break;

default:
    std::cout << "Неверное число";
}

Если ввели:

2

получим:

Вторник

---

34. "break" и "default"

Зачем нужен "break"?

Например:

case 1:
    std::cout << "Понедельник";
    break;

"break" говорит:

«Всё, выходим из "switch".»

Если забыть "break", программа может продолжить выполнять следующий "case".

Для новичка удобно запомнить:

case ...
    ...
    break;

"default"

Это вариант:

«Ни один "case" не подошёл.»

Например:

default:
    std::cout << "Ошибка";

35. Циклы

До сих пор программа выполняла команды один раз.

Но часто нужно повторить действие.

Например, вывести числа от 1 до 5.

Можно написать:

std::cout << 1;
std::cout << 2;
std::cout << 3;
std::cout << 4;
std::cout << 5;

Но это неудобно.

Для повторения существуют циклы.

Основные:

while
do while
for

---

36. "while"

Смысл:

«Пока условие истинно — повторяй.»

Например:

int number = 1;

while (number <= 5)
{
    std::cout << number << "\n";

    number++;
}

Результат:

1
2
3
4
5

---

37. Как работает "while"

Начинаем:

number = 1

Проверяем:

1 <= 5 → true

Выводим:

1

Увеличиваем:

number++

Теперь:

number = 2

Снова проверяем:

2 <= 5 → true

И так далее.

Когда:

number = 6

проверка:

6 <= 5

даёт:

false

Цикл заканчивается.

---

38. Опасность бесконечного цикла

Например:

int number = 1;

while (number <= 5)
{
    std::cout << number;
}

Здесь "number" никогда не увеличивается.

Поэтому условие всегда:

1 <= 5

и цикл бесконечный.

«⚠️ Следи за изменением переменной, от которой зависит условие цикла.»

---

39. "do while"

Похож на "while", но есть важная разница.

do
{
    // код
}
while (условие);

Код выполняется минимум один раз.

Например:

int number = 10;

do
{
    std::cout << number;
    number++;
}
while (number < 5);

Хотя:

10 < 5

неверно, число "10" всё равно будет выведено один раз.

Почему?

Потому что сначала выполняется код, а потом проверяется условие.

---

40. "while" vs "do while"

"while"

проверить
↓
выполнить
↓
проверить
↓
выполнить

"do while"

выполнить
↓
проверить
↓
выполнить
↓
проверить

Поэтому "do while" гарантированно выполняется хотя бы один раз.

Вот:

В нашем случае:

Начинаем с 1.

Пока "i" меньше или равно 5.

После каждой итерации увеличиваем "i" на 1.

61. Приведение типов

Иногда нужно превратить один тип в другой.

Например:

int number = 10;

Это можно сделать автоматически.

Но есть и явное преобразование:

double result = static_cast<double>(number);

Например, это полезно для деления:

int b = 3;

double result = static_cast<double>(a) / b;

Теперь получится:

3.33333...

Потому что "a" сначала превратился в "double".

62. Область видимости переменной

Это важно понимать до функций.

Например:

if (true)
{
    int number = 10;
}

Переменная "number" существует только внутри этих "{}".

Поэтому так нельзя:

if (true)
{
    int number = 10;
}

std::cout << number;

"number" здесь уже недоступна.

Но если:

int number = 10;

if (true)
{
    std::cout << number;
}

то можно.

Потому что "number" была создана снаружи блока.

«Главная идея: переменная доступна только внутри своей области видимости.»

63. Что такое память

Здесь начинается важная часть, особенно для темы архитектуры ЭВМ.

Когда мы пишем:

int number = 10;

компьютер должен где-то хранить "10".

Он выделяет участок памяти.

Условно:

Память
┌─────────────┐
│     10      │ ← number
└─────────────┘

У каждого участка памяти есть адрес.

Например, условно:

0x0012FF40

В реальности адрес будет другим.

---

64. Адрес переменной

У переменной есть адрес в памяти.

Получить адрес можно через:

&

Например:

int number = 10;

std::cout << &number;

Компьютер выведет что-то вроде:

0x7ff...

Это адрес переменной "number" в памяти.

65. Указатели — первое знакомство

До функций достаточно понять базовую идею.

Указатель — переменная, которая хранит адрес другой переменной.

Например:

int number = 10;

int* pointer = &number;

Здесь:

&number

означает:

«адрес "number"»

А:

int* pointer

означает:

«"pointer" может хранить адрес переменной типа "int".»

---

66. Получение значения через указатель

Если:

int number = 10;
int* pointer = &number;

то:

*pointer

означает:

«значение, которое находится по адресу, хранящемуся в "pointer".»

Поэтому:

std::cout << *pointer;

выведет:

10

67. Главное различие "&" и "*"

Это часто вызывает путаницу.

&number

→ адрес "number".

А:

*pointer

→ значение по адресу, который хранится в "pointer".

Можно представить:

number
┌──────┐
│  10  │
└──────┘
   ↑
   │ адрес
   │
pointer
┌──────────────┐
│ адрес number │
└──────────────┘

Запомни:

& → получить адрес
* → получить значение по адресу

74. Ещё один важный пример — поиск максимума

Допустим, пользователь вводит 3 числа.

#include <iostream>

int main()
{
    int a;
    int b;
    int c;

    std::cin >> a >> b >> c;

    int max = a;

    if (b > max)
    {
        max = b;
    }

    if (c > max)
    {
        max = c;
    }

    std::cout << max;

    return 0;
}

Если ввод:

10 25 7

получим:

25

Обрати внимание на логику:

1. Сначала считаем, что максимум = "a".
2. Проверяем "b".
3. Если "b" больше — максимум = "b".
4. Проверяем "c".
5. Если "c" больше — максимум = "c".

Это уже настоящее программирование — не просто знание команд, а построение алгоритма.

75. Что такое алгоритм

Алгоритм — это последовательность действий для решения задачи.

Например, задача:

«Найти сумму чисел от 1 до 5.»

Алгоритм:

1. Создать переменную "sum = 0".
2. Взять число 1.
3. Добавить его к "sum".
4. Взять число 2.
5. Добавить его к "sum".
6. Продолжать до 5.
7. Получить результат.

В C++:

int sum = 0;

for (int i = 1; i <= 5; i++)
{
    sum += i;
}

std::cout << sum;

Результат:

15

76. Как научиться решать задачи

Вот здесь самое главное.

Не надо сразу писать код.

Допустим задача:

Сначала словами:

1. Нужно ввести 5 чисел.
2. Первое число считаем максимальным.
3. Затем по очереди проверяем остальные.
4. Если новое число больше максимума — заменяем максимум.
5. После цикла выводим максимум.

Только после этого пишем C++.

«Сначала алгоритм словами → потом код.»

То есть функцию можно использовать, чтобы вынести отдельную часть программы в отдельный блок и потом вызывать её, когда это необходимо.

81. Проверка перед функциями

Если ты можешь самостоятельно понять, что делает этот код:

#include <iostream>

int main()
{
    int numbers[5];

    for (int i = 0; i < 5; i++)
    {
        std::cin >> numbers[i];
    }

    int max = numbers[0];

    for (int i = 1; i < 5; i++)
    {
        if (numbers[i] > max)
        {
            max = numbers[i];
        }
    }

    std::cout << "Max: " << max;

    return 0;
}

и можешь объяснить:

- что такое "int";
- зачем "numbers[5]";
- почему индексы начинаются с 0;
- что делает "for";
- зачем "i++";
- что проверяет "if";
- зачем "max = numbers[0]";
- почему второй цикл начинается с "i = 1";

значит, ты уже практически готов переходить к функциям.

Если какие-то вещи пока выглядят как магия — это абсолютно нормально.

Лучше сначала закрепить:

переменные
    ↓
условия
    ↓
циклы
    ↓
массивы
    ↓
строки
    ↓
основы памяти
    ↓
ФУНКЦИИ
